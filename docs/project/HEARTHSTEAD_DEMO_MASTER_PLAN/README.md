# Hearthstead Demo Master Plan — start her

Denne mappen er den autoritative planpakken for å gjenopprette, ferdigstille,
verifisere og levere Hearthstead-demoen fra første innlogging til Aftermath
etter første raid.

## Innhold

1. [`MASTER_PLAN.md`](MASTER_PLAN.md) — komplett gjennomføringskontrakt,
   demoavgrensning, gates, akseptansekriterier, testmatrise og releasekrav.
2. [`THREE_PASS_REVIEW.md`](THREE_PASS_REVIEW.md) — bevis på de tre separate
   kontrollrundene, funnene og endringene som ble gjort.
3. [`GATE_INDEX.md`](GATE_INDEX.md) — kort arbeidsrekkefølge og stoppunkter som
   brukes når arbeidet starter igjen.

## Nåværende status

- Planpakken er ferdig og tre ganger kontrollert.
- Gameplaykode, assets og JAR ble ikke endret under planarbeidet.
- Ingen tung QA-suite ble startet.
- Første tillatte arbeidssteg er **G0: Recovery og én autoritativ kilde**.
- Ingen implementasjon starter før Tobias eksplisitt ber om å gjenoppta
  arbeidet.

## Autoritetsregel

Hvis et eldre statusdokument, en gammel handover eller en løs chatmelding
motsier denne planens aktive demoavgrensning, skal konflikten først avklares i
Quality Ledger. Tester eller invariants endres aldri stille.
